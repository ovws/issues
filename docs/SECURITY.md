# 安全、许可与风险

## 网络边界

- 公网、端口映射、隧道和内网穿透均不在范围内。
- 局域网只开放 8001、8002、8003；上游 18001、18003 仅监听 `127.0.0.1`。
- 管理后台、账号池、Cookie 和上游密钥不经过局域网网关代理。
- Grok `/v1/media/*` 与 ChatGPT `/images/*` 只为呈现上游生成结果而公开到受防火墙保护的局域网；不代理管理 API。
- `/docs` 描述的是公司网关，不暴露上游管理 OpenAPI。

## 凭据与日志

- Gemini 内部密钥格式为 `sk-internal-...`，其 SQLite 只保存随机盐和 310,000 次 PBKDF2-SHA256 派生值。Grok/ChatGPT 使用各自上游原生个人密钥，8001/8003 原样转交 Authorization 并由上游校验；网关审计只保存不可逆指纹。
- 本机管理台固定监听回环地址并在应用层拒绝非回环客户端；状态变更另需同源动作令牌。
- Gemini 密钥轮换和幂等任务创建使用数据库事务与唯一索引，管理台不建立跨平台共享库；Grok/ChatGPT 密钥生命周期操作直接调用回环上游管理 API。
- 支持单独停用、到期时间和最后调用时间；永久删除仅允许已停用密钥，并保留独立审计事件。
- 日志过滤 Authorization、Cookie、Token、API Key、内部密钥和长 Base64。
- 任务表不保存请求正文、Cookie、完整密钥或上传图片 Base64。
- Gemini 媒体 URL 使用项目本地持久签名密钥；路径检查阻止目录穿越。

## 风控原则

- 不使用重要个人账号做测试。
- 不自动换号，不绕过验证码、Cloudflare 或平台限流。
- 401/403 视为凭据事件，停止平台并人工检查。
- 429 不自动切换账号；调用方退避，管理员检查额度与使用方式。
- 所有生成内容仍受公司数据分类、隐私、版权和内容安全制度约束。
